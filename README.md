# Waffenkontrolle

Browser-App für Aufbewahrungskontrollen nach § 36 WaffG.

- NWR-Stammdatenblätter (PDF) laden → Kontrollliste
- Pro Person: Waffen/Teile und Kaliber abhaken, Aufbewahrung, Unterschriften per Finger/Stift
- Abschluss erzeugt ein gesperrtes PDF-Protokoll

**Datenschutz:** Die Seite enthält nur das Programm. Alle Stammdatenblätter, Eingaben,
Unterschriften und PDFs werden ausschließlich im Browser des Geräts verarbeitet und
gespeichert. Es werden keine Daten an einen Server gesendet.

Verwendete Bibliotheken (eingebettet): pdf.js 3.11.174 (Apache-2.0), pdf-lib 1.17.1 (MIT), jsQR 1.4.0 (Apache-2.0), qrcode-generator 1.4.4 (MIT), pako 2.1.0 (MIT und Zlib).
